# DYAS-GoF-Patterns-Creational-PizzaFactory

Punto de partida (código sin refactorizar) para la **Parte I** del taller de Patrones Creacionales (Fábrica Abstracta).

El enunciado completo del taller (Parte I y Parte II) está en el README de [DYAS-GoF-CreationalPatterns-GameRefactoring](https://github.com/CesarAVegaF312/DYAS-GoF-CreationalPatterns-GameRefactoring) — revíselo antes de empezar.

Nota: `AmasadorPizza` (interfaz) y `AmasadorPizzaGruesa` (implementación) ya están resueltos a manera de ejemplo guía. Complete el resto (interfaces y clases equivalentes para `Horneador`/`Moldeador`, la fábrica abstracta `AFabricaPizza` y la variante de masa integral) siguiendo ese mismo patrón.
